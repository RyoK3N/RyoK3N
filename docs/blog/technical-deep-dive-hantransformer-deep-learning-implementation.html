### Core Algorithms

The core algorithms in HANTransformer are based on the Hierarchical Attention Network (HAN) and the Transformer architecture. The HAN is designed to process hierarchical structures, such as nested sequences (sentences in paragraphs, paragraphs in documents), by attending to the most relevant parts at each level. The Transformer architecture is used to capture long-range dependencies and global context in the text data.

#### Hierarchical Attention Network (HAN)

The HAN is composed of two levels of attention mechanisms: sentence-level and document-level. The sentence-level attention mechanism processes each sentence independently, while the document-level attention mechanism aggregates the sentence-level representations to form a document-level representation. This hierarchical structure allows the model to effectively capture both local and global information in the text.

#### Transformer

The Transformer architecture is based on self-attention mechanisms, which enable the model to weigh the importance of different parts of the input sequence. The model consists of multiple encoder and decoder layers, each containing self-attention and feed-forward networks. The use of positional encodings ensures that the model can process variable-length sequences.
